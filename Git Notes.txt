Git Notes1. Creating a GIT Repository--> To create a repository, create a directory and then convert it to a repository.git init <directory name>eg. git init newProject	mkdir - create a new folder	cd - change directory	ls -ls - check file contents	git init - used to create a git repository	ls -lrt - files in the directory	ls -la - hidden files in the directory	git status - used to check the status of the repository2. GIT Workflow-->	touch - used to create a file	git add - used to move the file to staging area	git commit -m <> - used to commit changes	echo - used to edit the file	git log - to view all the commits in reverse order	git log --oneline - to view online commit	git log --oneline --decorate --graph - to view commits in a structured way	3. Tracking File Changes-->	git diff - used to see changes made in files	vi - text editor in git	git diff --staged - used to see the changes after adding the files	4.Revert to Earlier Commits-->	git checkout -  command to revert to an earlier version	5. Deleting files -->	git rm <file name> - to remove a file from git 	git checkout HEAD~1 <file name> - to add back the deleted file 	6. Ignoring files-->	vi .gitignore - every file type written will be ignored		7. Rename files-->	git mv <file name> <new-file name> - rename files8. GitHub Commands-->	1.git remote add origin <GitHub repo link (https)> - to connect the git bash with GitHub	2.git branch -M main/master - to authenticate user	3.git push origin main - to push to local repo to GitHub repo	4.git pull origin master/main - to pull commits from GitHub repo	5.git remote remove origin - to remove origin (repo)	 9. Git Branches-->	git branch - used to list all branches	git branch <branch name> - creates a new branch		git checkout <branch name> - to switch between branches	git checkout -b <branch name> - create and switch the branch together	git merge <branch name> - to merge with master	git diff <branch name>..<branch name> - to know the diff betwenn branches	10. Git Stash-->	git stash save <stash message> - to confirm the stash	git stash list - to list all stashes	git stash apply - to continue the stash	git stash show - display number of files involved in stash	git stash clear - clear stash	11. Git Rebasing-->	git rebase <branch name> - to rebase the branch	12. Git cloning-->	git clone <repo name> <new repo name> - to create a clone of a repo	git clone <github repo name> - to clone github repo
